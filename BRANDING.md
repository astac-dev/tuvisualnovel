# Branding: TuVisualNovel

## Nombre del Proyecto y Marca

El nombre oficial y la marca registrada para este proyecto es **TuVisualNovel**.

### Reglas de Uso
1. **Consistencia:** Cualquier referencia al proyecto en la interfaz de usuario, títulos de página (HTML), metadatos, documentación, manifiestos PWA y material promocional debe utilizar exactamente **TuVisualNovel**.
2. **Capitalización:** Se debe respetar la capitalización CamelCase como se muestra (T y V y N en mayúsculas, el resto en minúsculas sin espacios).
3. **Restricciones:** No utilizar abreviaturas (e.g., TVN) en la interfaz orientada al usuario a menos que haya restricciones estrictas de espacio, y en tal caso, preferir el nombre completo o un logotipo si está disponible.
